# Add real product photos

Every product currently falls back to a light, minimal placeholder graphic. To
show real photography instead, download the free stock photos below (Pexels —
free for commercial use, no attribution required) and save each one under the
exact path listed. As soon as a file exists at that path, it replaces the
placeholder automatically — no code changes needed.

Tip: each category only needs 5 photos total; they're reused across that
category's 9 products, which is normal for a small catalog. Swap in your own
product photography whenever you have it — same file paths, same effect.
